# Installation

For best performance, we recommend running models built with Terrax on a
computer with an attached GPU or TPU. Otherwise, performance might be slow.

You can install Terrax from source using pip, which should automatically
install its dependencies, including [JAX](https://github.com/jax-ml/jax),
[Coordax](https://github.com/neuralgcm/coordax), and
[Dinosaur](https://github.com/neuralgcm/dinosaur):
```
pip install terrax
```
